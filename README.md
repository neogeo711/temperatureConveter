# Temperature Converter

A simple JavaScript temperature converter between Celsius and Fahrenheit.

Project idea from roadmap.sh: https://roadmap.sh/projects/js-temperature-converter

## Functions

- `celsiusToFahrenheit(celsius)` - converts Celsius to Fahrenheit and returns the number.
- `fahrenheitToCelsius(fahrenheit)` - converts Fahrenheit to Celsius and returns the number.
- `formatTemperature(value, unit)` - returns display text such as `"77 F"` or `"20 C"`.

## Usage

Requires [Node.js](https://nodejs.org/).

```bash
node tempConverter.js
```

Example output:

```
77 F
20 C
32 F
0 C
```
